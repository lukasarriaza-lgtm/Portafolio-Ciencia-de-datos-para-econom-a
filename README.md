Monitor de Coyuntura y Proyección Macroeconómica \
Integrantes: Felipe Alviña, Lukas Arriaza, Javier Vidal, Matías Vidal

Esta propuesta presenta un proyecto de análisis y proyección del tipo de cambio nominal peso/dólar (USD/CLP) para el período 2026–2028, desarrollado desde la perspectiva de una 
consultora económica especializada en asesoría cambiaria. El trabajo integra análisis de coyuntura con modelación econométrica rigurosa, siendo el pronóstico y su evaluación 
elementos centrales del ejercicio.
